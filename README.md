# Realtor Decision Assistant (RDA) — Early AI Prototype

**A free, experimental example of using structured AI instructions to help real estate agents think through decisions.**

Realtor Decision Assistant (RDA) began as an exploration of a simple question: *Can thoughtfully designed instructions make a general-purpose AI assistant more useful in the everyday decisions real estate agents face?*

This repository shares a **lightweight, early Markdown prototype** of that idea. It can help you evaluate an offer, think through a struggling listing, brainstorm marketing ideas, and draft client communications. It is not the full RDA application.

## Try the prototype

**File:** [`RDA_Early_AI_Prototype.md`](RDA_Early_AI_Prototype.md)

You do not need to install a Plugin or write code to try the Markdown version.

### Option A — Quick test in ChatGPT

1. Open the Markdown file above on GitHub and select **Raw**, or copy its contents.
2. Start a **new chat** in ChatGPT.
3. Paste the Markdown instructions, followed by a request such as: *“Use these RDA prototype instructions to help me evaluate a buyer's offer.”*
4. Describe your situation, including relevant facts, and ask follow-up questions as needed.

You can also upload the `.md` file to a chat if your ChatGPT interface supports file uploads, then ask ChatGPT to use it as guidance for the conversation.

**Tip:** Starting a new chat with the instructions is the easiest way to experiment. Pasting instructions into a conversation is not the same as installing a persistent Plugin, and the AI may not follow every instruction perfectly.

### Option B — Build your own private assistant

If your ChatGPT account provides GPT creation, you can create a **private custom GPT** and adapt the prototype's instructions for its configuration. Availability and sharing options depend on your account and current ChatGPT product settings. A private GPT is not required to use this example.

## Example questions

- **Offer evaluation:** “A home is listed for $650,000. We received an offer of $620,000 with conventional financing and an inspection contingency. Help me evaluate the offer and possible counters.”
- **Listing review:** “My listing has been on the market for 60 days with limited showings. Act as a broker-style adviser and help me identify what to review.”
- **Client communication:** “Draft a professional email to a seller explaining why we should revisit our pricing strategy.”
- **Marketing:** “Help me develop a basic marketing plan for a home with first-floor living and nearby amenities.”

These are hypothetical examples. Provide accurate information about your own situation and verify any recommendation before using it.

## What this version includes

- Broker-style reasoning and practical next steps
- Basic offer and listing analysis
- Client communication drafting
- Introductory listing marketing guidance

## What it does **not** include

The Markdown file does **not** provide live MLS data, verified comparable sales, a CRM, persistent client records, reminders, checklists integrated with tasks, document processing, or other application integrations. It is a set of instructions, not a working real estate software platform.

## What about the RDA Plugin?

A separate **Realtor Decision Assistant — Beta** Plugin has been developed for private experimentation. **It is not currently being offered here as a publicly installable Plugin.** A Plugin link alone does not guarantee access for other ChatGPT users.

For now, the **public way to experiment is the Markdown file in this repository**. If wider Plugin distribution becomes available, this README can be updated with verified installation instructions.

## Responsible use

RDA is a decision-support experiment, **not a substitute for a licensed supervising broker, attorney, or other qualified professional**. Verify market data, contract terms, legal requirements, and local real estate rules independently. Avoid entering unnecessary personal or confidential client information into AI tools, and follow your brokerage's policies and applicable privacy requirements.

## Feedback and project direction

This is an early learning project, not a finished commercial product. I'm interested in what real estate agents find useful, where the advice falls short, and which everyday decisions are worth exploring next.

If you've tried the prototype, consider opening a GitHub issue with a scenario, suggestion, or observation—**without including private client information**.

The broader RDA project explores more advanced workflows and integrations, but those are outside the scope of this prototype.
